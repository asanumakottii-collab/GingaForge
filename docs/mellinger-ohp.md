# Mellinger方式（mellinger-ohp）

Axel Mellinger の科学用全天パノラマ FITS を銀河座標で再投影した、白黒階調の OHP 用原盤です。
観測された天の川の濃淡と暗黒帯を利用し、手描きの補完・RC3 銀河の疑似星化は使用しません。

肉眼の印象に近づけるため、次の処理をします。

1. 青と緑を混ぜる（[色の混合](#色の混合)）
2. 恒星投影機・1等星投影機が映す星を除き、それより暗い星の光は霞として天の川に戻す（[星の除去](#星の除去)）
3. 原盤上の位置へ再投影する（[投影式](#投影式)）
4. 白黒の階調に変換する（[階調変換](#階調変換)）

Gaia方式とは入力も処理も別で、設定キーの名前も共通ではありません。

## 印刷するファイル

`output/mellinger-ohp/mellinger-ohp-plates.pdf`：A4・1ページに2列×2段で、上段の左から N0 / S0、下段の左から N1 / S1 を配置します。
黒い正方形の枠は95 mm四方です。各区画は8ビットグレースケール画像で、物理寸法を正確に指定して配置しています。

| 区画 | 銀経 l | 銀緯 b | 紙面の上 → 下 |
|---|---|---|---|
| N0 | 0–60° | −20–+20° | 60 → 0° |
| N1 | 60–120° | −20–+20° | 120 → 60° |
| S0 | 300–360° | −20–+20° | 360 → 300° |
| S1 | 240–300° | −20–+20° | 300 → 240° |

- 全区画で紙面の左が銀緯 −20°、右が +20°です。銀経0°と360°は同じ方向です。
- 各画像の外周が範囲の境界に対応し、画素は境界の内側の画素中心をサンプリングします。境界の重複画素やフェザー処理はありません。
- **A4・倍率100%・「用紙に合わせる」なしで印刷**してください。同梱設定の画像は幅約15.29 mm × 高さ約22.00 mm です（PDFの下部に正確な寸法を記載）。
- 黒は遮光、白はインクを置かない透明部分、灰色は中間の透過を意図します。白インクは不要です。
- ラベルと位置合わせマークは画像領域の外側にあります。取り付け時は画像領域以外を遮光してください。
- 紙面座標はOTLの計算方向に合わせてあり、鏡像処理はしていません。フィルムの表裏・レンズによる左右反転は取り付け方向に依存するため、
  ラベルの銀経・銀緯方向を実機で照合してください。

## 色の混合

RGB FITSの3面（青・緑・赤の順。赤いアンタレスと青いシャウラの明るさの比で確認）を `channel-weights` で重み付き平均します。

- 初期値は青0.5・緑0.5・赤0で、暗い所で働く目の感度（ピーク507 nm）を青と緑で近似したものです。
- Hα輝線（肉眼ではほぼ見えない）を含む赤は使いません。
- 緑のみ（`0, 1, 0`）と比べると、塵で赤くなった銀河中心のふくらみが控えめになり、塵の少ないりゅうこつ座付近が相対的に明るく、暗黒星雲はやや深くなります。
- いずれもGaiaのG等級や厳密な暗所視感度とは同一ではありません。元FITSには強度の物理単位（BUNIT）がありません。

## 星の除去

恒星投影機（1.5等より暗く7.5等まで）と1等星投影機（1.5等以下、惑星を含む）が映す星を原盤から除き、
それより暗い星の光は霞として天の川に戻します。

元画像の星を点のまま残すと、白く飽和した星の点が原盤全体に散らばって天の川が目立たず、恒星投影機の星とも重なります。
7.5等以下の星だけを除いても、残る7.5〜11等程度の星（多くは銀河面に集中しない手前の星）の点で、天の川の中と外の比はほとんど変わりません。
そのため暗い星は点ではなく霞として戻します。肉眼でもおよそ7等より暗い星は1つずつは見えず、天の川の光の一部として見えます。

1. **StarNet2 で分ける**：色を混ぜた全天画像を、可逆なasinh変換で0〜20000を16ビットにしてTIFFで `starnet2 -u` に渡し、
   星を除いた画像 S を元の強度に戻します。20000を超える値（明るい星の芯）は切り詰めます。元画像との差が星の層 T です。
   Mellinger の星は1〜3画素と小さく、2倍アップサンプリング（`-u`）なしでは暗い星が粒状に多く残ります。全天で約30秒かかります。
2. **投影機が映す星を除く**：OTLと同じHipparcos星表から V ≦ `star-catalog-limit-mag`（7.5、この値を含む）の星を選び
   （全天25,713個、4区画内8,190個）、その位置の周りの T を捨てます。
   - 半径は7.5等で0.15度、1等明るくなるごとに0.05度広げます。星表と画像の位置のずれは中央値0.25〜0.6画素でした。
   - OTLの恒星原盤と同じ欄（V等級、ICRS・J1991.25の赤経・赤緯）を読み、等級か位置が空欄の星は除きません（OTLでも投影されないため）。
   - 3等以下の星の周りには StarNet2 が淡いにじみを残す（1.5等より明るい星で半径約0.5度、+7〜9%）ため、
     除く範囲の1.5倍の円内の S を周囲の明るさで埋め直し、円の縁はぼかして混ぜます。
3. **暗い星は霞として戻す**：残りの T（7.5等より暗い星）を1画素あたり `faint-star-cap`（500）で頭打ちにし、σ = 0.3度でぼかして S に足します。
   除いた星の円の中は、周りの暗い星の光の平均で埋めます。
   - 頭打ちが必要なのは、元画像が細かい画像を双線形補間で縮小しているためです（FITSヘッダーの `RESAMPT1 = BILINEAR`）。
     鋭い星は中心の明るさが1画素だけに写り、同じ等級でも画素値が数十倍ばらつきます（7.5〜8等で中央値約250、上位10%は2500以上）。
     頭打ちにしないと、このばらつきが0.3度ほどの丸い塊として残ります。初期値で暗い星の光の約73%を残します。

除いた星の位置の明るさは、周囲（半径1.0〜1.4度の輪）との差が1.5等より明るい星で+3%以内、それ以外で1%以内です。

注意点：

- 0.5度程度より小さい球状星団・散開星団・小さな星雲も、星と同じく StarNet2 で分けられ、霞として戻ります。
  例えばケンタウルス座ω星団（Hipparcosの星ではない）は淡い塊として残ります。
- OTLは、HIP番号のない Tycho の星（`tyc_main.dat`）も同じ等級範囲で投影しますが、この方式では使いません。
  4区画内の V ≦ 7.5 の Tycho のみの星は648個です。Hipparcos の星から0.2度以上離れた約500個は、ほぼすべて6.5〜7.5等で、点ではなく霞として薄く広がります。
- OTLの `star.excluding`（個別に除外したHIP番号）は反映しません。OTLで除外した星も原盤から除かれます。
- `star-removal = none` にすると、星を除かず点のまま残します（StarNet2 も星表も使いません）。黒点は210前後が目安です。

## 投影式

投影機がドーム中心にある構成（中心配置）だけに対応します。原盤の大きさは、OTLと同じくレンズの焦点距離から決めます。

1. 原板は投影機中心から `plate-distance-mm`（P）の位置にあり、原板からドームまでの距離は `dome-radius-mm`（R）− P です。
2. 原板とレンズの距離 L を、レンズの公式 `1/f = 1/L + 1/(R − P − L)`（f は `focal-length-mm`）の小さい方の解とします。
3. レンズ中心はドーム中心から d = P + L だけ原盤中心の方向に出た位置にあります。

原盤上の点は、レンズ中心からの円筒投影で決まります（角度はラジアン、xは紙面右向き、yは紙面下向き）。

```
x = L × tan(β)
y = −L × α
```

α・βは、レンズ中心から見た光線の方位（原盤中心から銀経の方向）と仰角（銀緯の方向）です。
光線とドーム（半径R）の交点から銀経・銀緯を求め、FITSのWCSで全天画像上の画素位置を求めて双線形補間します。
d = 0 なら α = l − l_center、β = b です。
元画像の強度を補間するだけで、面積ヤコビアンは掛けません。レンズ・光源の周辺減光の補償はありません。

画像の寸法は、レンズ中心から見たドーム上の銀経±30度・銀緯±`latitude-limit-deg`（b）の点で決まり、`print-scale` を掛けます。

- 高さ = 2 × L × atan2(R sin 30°, R cos 30° − d) × `print-scale`
- 幅 = 2 × L × R sin b / (R cos b − d) × `print-scale`

同梱の設定（f = 19、P = 50、R = 6500、print-scale = 1）では L ≈ 19.06 mm、幅約14.03 mm × 高さ約20.16 mm です。
`print-scale` はOTLの `scale` と同じく長さのすべてに掛かるため、焦点距離を含めた全体の相似縮小になります。

## 階調変換

4区画共通で、色の混合と星の除去を終えた強度 F を、次の順で 0（黒、遮光）〜255（白、透明）の画素値にします。
区画ごとの自動露出・局所的なコントラスト補正は行いません。

```
u = clip((F − black-level) × exposure / (white-level − black-level), 0, 1)
v = asinh(u / asinh-softening) / asinh(1 / asinh-softening)   # tone-mode = asinh のときだけ
pixel = round(255 × v^(1 / display-gamma))
```

- 黒点180・白点600は、初期設定（青0.5＋緑0.5、星の除去あり）の4区画を300 dpiで再投影した値の約30・99パーセンタイル（181・612）です。
- **画素値は空の表面輝度に比例しません。** プリンターの灰色値と実際のフィルム透過率も一致するとは限りません。
  同じプリンター・フィルム・インク・設定で試し刷りし、黒の光漏れと灰色の透過を確認してください。
- 白黒原盤のため、長時間露光写真の色は再現しません。

## 設定（`mellinger-ohp.properties`）

値と同じ行にはコメントを書けません。行頭に空白を入れると前の行の続きとみなされます。

| 設定 | 同梱の値 | 意味 |
|---|---:|---|
| `source-fits` | source/mwpan2_RGB_3600.fits | Mellinger の科学用 RGB FITS |
| `channel-weights` | 0.5, 0.5, 0 | 青・緑・赤の重み。合計で割って使う |
| `star-removal` | starnet | starnet: 星を除く / none: 星を点のまま残す |
| `starnet-command` | （空欄） | StarNet2 の実行ファイル。空欄なら自動で探す（下記） |
| `starnet-upsample` | yes | StarNet2 の2倍アップサンプリング（`-u`） |
| `star-catalog` | source/hip_main.dat.gz | 除く星の星表（Hipparcos） |
| `star-catalog-limit-mag` | 7.5 | この等級以下（V等級、この値を含む）の星を除く。OTLの `star.minimum` に合わせる |
| `star-mask-radius-deg` | 0.15 | `star-catalog-limit-mag` の星で除く範囲の半径（度） |
| `star-mask-growth-deg-per-mag` | 0.05 | 1等明るくなるごとに広げる半径（度） |
| `halo-fill-limit-mag` | 3 | この等級以下の星の周りのにじみを埋め直す |
| `faint-star-blur-deg` | 0.3 | 暗い星の光をぼかす幅（ガウス関数のσ、度）。0ならぼかさない |
| `faint-star-cap` | 500 | ぼかす前に暗い星の光を1画素あたりこの値で頭打ちにする |
| `faint-star-weight` | 1 | 暗い星の光を戻す割合（0〜1）。0にすると星の光をすべて捨てる |
| `dome-radius-mm` | 6500 | ドームの半径（mm） |
| `plate-distance-mm` | 50 | 投影機の中心から原盤の中心までの距離（mm）。原盤の大きさへの影響は小さい |
| `focal-length-mm` | 19 | レンズの焦点距離（mm）。原板とレンズの距離をレンズの公式から求め、画像の大きさを決める |
| `projector-horizontal-mm` | 0 | 投影機の偏心（赤道面に平行な成分）。0以外はエラー |
| `projector-vertical-mm` | 0 | 投影機の偏心（赤道面に垂直な成分）。0以外はエラー |
| `latitude-limit-deg` | 20 | 原盤の左右の端の銀緯（度）。Gaia方式とそろえるため通常は20 |
| `print-scale` | 1 | 長さの設定すべてに掛ける倍率。画像の幅・高さが変わり、黒枠と配置は変わらない。幅79 mm・高さ43 mmを超えるとエラー |
| `raster-dpi` | 1200 | 再投影した画像の解像度（72〜2400）。上げても観測情報は増えない |
| `tone-mode` | asinh | asinh: 暗い部分を持ち上げる / linear: 線形 |
| `black-level` | 180 | これ以下を黒（遮光）にする。上げると外側が黒く締まり天の川が細くなる |
| `white-level` | 600 | これ以上を白（透明）にする（exposure = 1 のとき） |
| `asinh-softening` | 0.4 | asinh 圧縮の強さ。小さいほど暗い部分が明るく持ち上がる |
| `exposure` | 0.5 | 明るさの倍率。全体が暗ければ上げる |
| `display-gamma` | 1 | 最後に掛けるガンマ。1より大きいと中間調が明るくなる |

## StarNet2 の導入

StarNet2（Mikita (Nikita) Misiura）は利用条件で再配布・同梱が禁止されているため、このリポジトリには含めません。
`gingaforge install-starnet` が、利用条件で認められた方法（公式配布元から直接ダウンロード）で `tools/starnet2/` に導入します。
`tools/starnet2/` は git の対象外です。コミットしたり、他の場所から配ったりしないでください。

```sh
# 公式の最新版フィード（https://starnetastro.com/cli-tools/latest.json）から今のOS向けのZIPを取得
.venv/bin/gingaforge install-starnet

# 公式サイトから手で取得したZIP、またはそれを展開したフォルダから導入
.venv/bin/gingaforge install-starnet --from ~/Downloads/starnet2_macos-arm64_2.6.2-0242_COREML_arm64_cli
```

- **ダウンロードの検証**：フィードのURLが公式配布元（`starnetastro.com`、`download.starnetastro.com`）であることを確かめ、
  ZIPをフィードのサイズとSHA-256で照合してから展開します。展開先の外を指すZIPの項目は拒否します。
- **利用条件への同意**：使う前に利用条件の全文（配布物の `LICENSE.txt`）を示し、同意を得ます。
  同意した条文のSHA-256を `tools/starnet2/accepted-licenses.json` に記録するので、同じ条文には一度だけ同意すればよく、改訂されたら同意し直します。
  対話できない環境では、全文を読んだうえで `--accept-starnet-license` を付けます（`gingaforge mellinger-ohp` にも同じオプションがあります）。
- **使う実行ファイルの順番**：`starnet-command` が空欄なら、①`tools/starnet2/` に導入したもの、②PATH 上の `starnet2` の順に探します。
  どれも見つからないとき、対話できる端末なら導入するかを尋ね、対話できない環境では導入方法を示して止まります。
- **実行時の表示**：使った StarNet2 の版とパスを表示し、PDF の見出しにも StarNet2 を使ったことを書きます。

利用条件では、StarNet2 の出力を機械学習の学習に使うことや、他のソフトウェアの開発・テストの素材・基準結果に使うことも禁止されています。
テストは StarNet2 をその場で動かすだけで、出力を正解データとして保存しません。

初期設定の原盤は StarNet2 2.6.2 で生成しています。2.5.3 で生成した前の版との差は、PDFの画素値で平均1.2（0〜255）でした。

## 再生成

```sh
.venv/bin/gingaforge mellinger-ohp
.venv/bin/python -m unittest -v tests.test_mellinger_ohp tests.test_starnet_setup
```

元画像は自動取得しません。ない場合は下記URLから取得して `source/mwpan2_RGB_3600.fits` に置いてください。
StarNet2 の実行を含め、全体で約40秒かかります。
